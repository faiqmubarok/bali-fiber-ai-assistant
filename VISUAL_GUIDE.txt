    │
    ├─→ Lokal:
    │   └─→ Edit .streamlit/secrets.toml
    │       └─→ GEMINI_API_KEY = "your-key"
    │
    └─→ Cloud:
        └─→ Streamlit Cloud Dashboard
            └─→ Settings → Secrets
                └─→ Add: GEMINI_API_KEY = "your-key"

    ❌ ERROR: "cluster_db not found"
    │
    └─→ Jalankan notebook AI_2_FIXED.ipynb
        └─→ Generate database
            └─→ Copy folder cluster_db ke project

    ❌ ERROR: "Model not found"
    │
    └─→ Edit app.py baris ~101
        └─→ Ganti ke: gemini-1.5-flash
            └─→ Save & restart

    ❌ App sangat lambat
    │
    └─→ Normal untuk pertama kali!
        └─→ Download model (~90MB)
            └─→ Setelah itu akan cepat
